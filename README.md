# 🏥 Hospital Management System

A simple and user-friendly **Hospital Management System** developed as my first web development project.

## 📌 About the Project

The Hospital Management System is a web-based application designed to manage basic hospital activities such as patients, doctors, appointments, and billing.

This project helps me understand the fundamentals of **HTML, CSS, Bootstrap, and JavaScript** while developing a real-world application.

## ✨ Features

* 🏠 Hospital Dashboard
* 👨‍⚕️ Doctor Management
* 🧑‍🤝‍🧑 Patient Management
* 📅 Appointment Management
* 💰 Billing Management
* 📋 Recent Appointments
* 📊 Dashboard Statistics
* 📈 Charts and Data Visualization
* ➕ Add Patient through a form
* 🔎 Patient information management

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript
* Chart.js
* Excel / Power BI for data visualization

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the sidebar to navigate between different pages.

## 📊 Dashboard

The dashboard displays important hospital information such as:

* Total Patients
* Total Doctors
* Appointments
* Revenue
* Recent Appointments
* Patient Statistics

## 🎯 Project Objective

The main objective of this project is to develop a simple hospital management website and gain practical experience in front-end web development.
